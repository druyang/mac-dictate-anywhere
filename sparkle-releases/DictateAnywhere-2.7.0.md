# Dictate Anywhere 2.7.0

- Added context-aware dictation that adapts cleanup and insertion to the active app, website, cursor position, and nearby text.
- Added separate writing styles for email, work messaging, personal messaging, and other apps, including Formal, Neutral, Casual, Excited, Very Casual where supported, and Original tone.
- Improved mid-sentence insertion so ordinary words use surrounding capitalization, adjacent punctuation is respected, and visible names and custom vocabulary keep their spelling.
- Improved email formatting with natural greeting, body paragraph, sign-off, and signature structure.
- Added privacy controls for surrounding text. Nearby text stays on this Mac unless remote sharing is explicitly enabled, and secure fields, password managers, and excluded apps are never read.
- Improved AI cleanup response handling and reasoning-format normalization.
- Updated Sparkle to 2.9.6 with the latest updater security fixes and hardened the GitHub release workflow.
